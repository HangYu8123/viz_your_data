# Figure cards — explaining axes, values and claims (viz/figures.md)

Every figure ships with a card, and the chat message after the build repeats
the card's essence (≤5 lines per figure, the rest stays in figures.md). The
reason: a figure whose axes the author cannot explain in one sentence is not
ready, and a figure that does not name the claim it supports will be cut by a
reviewer.

## What must be true of every figure (checked by `st.save`)

1. **x and y are named, with units**: use `st.label_axes(ax, x=…, y=…,
   yunit=…, direction="lower is better")` → "Interventions [count / trial]
   (lower is better)". Unitless quantities say so (score, ratio, count).
   `st.check_axes` warns on missing labels or units; fix before moving on.
2. **Values are readable**: bars carry their numbers (`st.value_labels`) when
   the numbers matter; ticks cover the data range without dead space; the
   aggregation level and error-bar type are stated in the card.
3. **The claim is named**: `meta={"claim": "H1", "hypothesis": …}` in
   `st.save`, and the card's reading says *which visual feature* shows the
   claim ("all paired lines slope down", "CI of C3 excludes C1's mean").
4. **Significance is on the figure** when statistics ran: `st.annotate_sig`
   (bracket with stars + effect size) for two-group claims,
   `st.annotate_posthoc` for ANOVA pairs, `st.stats_footer` for correlations
   or crowded panels. The caption then repeats the exact test line from
   statistics.md. Stars alone are not enough — show the effect size next to
   them, and say in the card which test and correction produced the p.

## Card template (generated by `build_figure_cards.py`)

```markdown
## F1_interventions — H1
**File:** `F1_interventions.pdf` · **width:** single (3.5 × 2.4 in)
**Claim (H1):** Fewer takeovers with visual explanation (C3 < C1)

**What the axes mean**
- Single panel:
  - x: Condition; ticks: C1, C3
  - y: Interventions [count / trial] (lower is better) — unit: count / trial; range 0 to 9.2
  - legend / series: C1, C3
  - annotations: ***  d = 1.56

**What the values are**
- one value per participant (mean over trials), n=12; gray lines connect the same participant; bar = condition mean
- source: trials.parquet: participant, condition, interventions
- Significance shown: paired t-test, Holm-adjusted p as stars, Cohen's dz — paired t-test, p < .001 (Holm-adjusted), cohen_dz = 1.56 [0.89, 3.74]; verdict: supported

**How to read it / why it supports the claim**
- every gray line slopes down from C1 to C3 and the C3 mean is 1.6 lower with a large effect, so participants take over less with visual explanations
```

Axes, ranges, ticks, legend and annotations are read from the saved figure;
only `claim`, `hypothesis`, `values`, `source`, `significance`, `reading`
(and optional `caveats`) are written by the agent through `meta`.

## The chat explanation

After the build (and after every revision), explain each figure in this
shape — first line what to open, then per figure:

```
**F1_interventions** (single width) — H1
- x: Condition; y: Interventions [count / trial] (lower is better)
- values: per-participant means, n=12, paired lines; paired t p < .001, dz = 1.56 → supported
- supports H1: all lines slope down; C3 mean 1.6 lower, large effect
```

Show at most five figures inline; point to figures.md for the rest.
